# ProjectDesk — Тёплый вечер

Личный настольный органайзер: **ежедневник и заметки**, без аккаунта, облака и финансового раздела. Форк [crucifiedshepherd/ProjectDesk](https://github.com/crucifiedshepherd/ProjectDesk) с новым оформлением в стиле «Тёплый вечер».

## Что есть

- **Главная:** актуальные задачи, ближайшие дедлайны, быстрая заметка и списки «На этой неделе» / «Позже».
- **Ежедневник:** задачи, группы, приоритеты, сроки, перенос между группами, история выполненных дел.
- **Заметки:** категории, поиск, автосохранение, дополнительные поля и простые Markdown-вставки с предпросмотром.
- **Настройки:** имя в приветствии и включение/отключение фонового изображения.

Интерфейс: React + TypeScript + CSS. Настольная оболочка: Tauri 2 + Rust. Данные: SQLite через `@tauri-apps/plugin-sql`.

## Запуск на macOS

Требуются Node.js, Rust с Cargo и Xcode Command Line Tools.

```bash
npm install
npm run tauri dev
```

Сборка установщика:

```bash
npm run tauri build
```

## Данные и совместимость

База данных `deskdata.db` сохраняется локально в каталоге приложения. Идентификатор Tauri сохранён `com.shepherd.projectdesk`, чтобы не потерять путь к базе у пользователей исходной версии. Финансовый экран удалён, но существующие старые таблицы SQLite **не очищаются автоматически**: это сделано во избежание потери данных.

Фон `src/assets/warm-evening.jpg` используется с затемнением, чтобы текст оставался читаемым. В режиме отключённого фото приложение использует CSS-градиент.

### Иконка

Иконка создаётся из исходника `src/assets/projectdesk-icon.svg`. При каждом `npm run tauri dev` или `npm run tauri build` скрипт `pretauri` генерирует PNG, ICNS и ICO в `src-tauri/icons-generated/` – поэтому новая иконка появляется в Dock и собранном приложении без ручных действий. Эти сгенерированные файлы не коммитятся; изменяй исходный SVG. Для изменения иконки в Dock может понадобиться перезапустить приложение.
