# ProjectDesk

Небольшой настольный органайзер для задач, дедлайнов и заметок. Работает локально, без обязательного аккаунта и облачной синхронизации.

## Возможности

- **Главная:** задачи на сегодня и ближайшие дела слева, быстрая заметка и календарь дедлайнов справа. В календаре можно листать месяцы, выбирать день, отмечать задачи и создавать задачу сразу с нужной датой.
- **Ежедневник:** задачи с группами, приоритетами, сроками, отметками выполнения и переносом между группами.
- **Заметки:** категории, поиск, автосохранение, дополнительные поля и простой Markdown-редактор с предпросмотром.
- **Настройки:** имя на главной, отображение фонового изображения, яркость фона и плотность интерфейса (обычная или компактная). Выбор сохраняется локально.

Проект построен на React, TypeScript, Tauri 2, Rust и SQLite.

## Запуск на macOS

Нужны Node.js, Rust/Cargo и Xcode Command Line Tools.

```bash
npm install
npm run tauri dev
```

Сборка приложения:

```bash
npm run tauri build
```

## Данные

Задачи и заметки хранятся локально в SQLite (`deskdata.db`). Идентификатор Tauri (`com.shepherd.projectdesk`) оставлен прежним для совместимости с уже созданной базой данных.

Изображение оформления: `src/assets/warm-evening.jpg`. Исходник иконки: `src/assets/projectdesk-icon.svg`. При запуске Tauri автоматически генерирует нужные форматы иконок в `src-tauri/icons-generated/`.
